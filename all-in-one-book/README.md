# Kanboard 后端技术全局分析书

> **本书价值**：本书是 propress/fork-kanboard 项目后端源码的全景式技术分析。它不是一本 API 文档，也不是逐行代码注释——而是一张帮助你快速建立项目心智模型的**技术地图**。读完后，你将理解项目的架构分层、数据组织、核心机制运作方式和关键业务流程，并能评估它是否适合你的场景、改造难度有多大。

## 🗺️ 建议阅读顺序

1. **先读第一章**——用 5 分钟了解项目是什么、用了什么技术
2. **再读第二章**——建立架构全景图，理解请求怎么从入口走到数据库再返回
3. **然后读第三章**——看懂数据是怎么组织的，表和表之间什么关系
4. **接着读第四章**——了解七大核心机制各自怎么运作
5. **重点读第五章**——这是本书最核心的章节，通过流程图理解业务怎么跑通
6. **最后读第六、七章**——做出"用不用、怎么改"的决策

> 💡 如果你时间有限，**第二章 + 第五章** 是最小必读集——架构全景 + 业务流程足以让你上手。
